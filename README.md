# 回答錄音機

手機優先的純前端 PWA。使用者可以建立問題、錄製或上傳回答音檔，之後點選大按鈕即可播放回答。

## 功能

- 本機 IndexedDB 儲存問題、排序、設定與音檔
- 播放模式與管理模式分離，降低誤操作
- 支援錄音、上傳音檔、重新錄製
- 支援最愛置頂與排序
- 支援 ZIP 匯出備份與匯入還原
- 支援 PWA 安裝與 Service Worker 離線使用
- 支援捷徑網址，例如 `index.html?play=<問題ID>`

## 部署

此專案是靜態網站，可直接部署到 GitHub Pages、Vercel、Netlify 等 HTTPS 服務。

錄音功能需要 HTTPS。使用 `http://192.168...` 區網網址測試時，手機瀏覽器通常不允許使用麥克風。
